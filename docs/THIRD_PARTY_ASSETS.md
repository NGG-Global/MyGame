## What the project does with them

- **Import** (`DisplayAircraftImport`): geometry and material names only; no
  animation, cameras, lights or blend shapes. The source meshes are not referenced by
  the scene, so they do not enter the build.
- **Bake** (`DisplayAircraft`, run by the scene builder): each model becomes one
  static mesh asset in `Assets/_Game/Art/Meshes/Display/` with one submesh per colour
  role (paint, secondary, metal, glass, tyre, dark, red and green lights), positions and
  normals only, mesh compression Medium.
- **Colours**: flat project materials replace the missing textures (F-16 light grey,
  Spitfire dark green, Beechcraft red; shared glass, metal, tyre and dark materials).
- **Parts**: the F-16 ships with parked and in-flight versions of its gear doors, flaps
  and slats; one of each pair is kept (the visible one, else the parked one unless it is
  stored away from the airframe). External stores on the F-16 are kept as supplied.
- **Size and placement**: each model is scaled to the real aircraft's wingspan
  (approximate public figures: F-16 9.96 m, Spitfire 11.23 m, Beechcraft Model 17
  9.75 m) and parked nose east on the apron.

## Names and trademarks

The game shows no names for these aircraft. File and object names use the real
names by the owner's decision. Real aircraft names, designs and liveries can be
protected by trademarks or other rights; whether a licence is needed for a commercial
release is a legal question for the owner and their adviser, not something this
repository can settle.

## Generated content (not third-party)

All sounds (`PlaceholderAudio`), runtime sprites, ground and sea textures, tree meshes
and the audio mixer are generated by the project's own code.
